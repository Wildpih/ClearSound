# 🎵 ClearSound

**Удаление голоса из аудио/видео и интеллектуальное восстановление звуковой дорожки.**

ClearSound не просто удаляет голос — он анализирует «пробелы», оставшиеся после удаления, находит подходящие звуки из библиотеки и вставляет их, восстанавливая полноценное звучание.

---

## 🚀 Возможности

- **Удаление голоса** — использует модель Demucs (Facebook AI) для высококачественного отделения вокала
- **Анализ пробелов** — определяет участки, где был голос, и оценивает потерю энергии
- **Подбор звуков** — ищет в библиотеке звуки, спектрально похожие на окружение
- **Умная вставка** — кроссфейды, подгонка громкости, time-stretch, спектральное формирование
- **Интерактивный просмотр** — послушайте результат, сравните с оригиналом, подкорректируйте
- **Поддержка видео** — автоматически извлекает аудио из видеофайлов (MP4, MKV, AVI и др.)

## 📋 Алгоритм работы

```
Входной файл (видео/аудио)
    │
    ▼
┌─────────────────────────┐
│  1. Удаление голоса     │  ← Demucs source separation
│     (вокал отделяется)  │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  2. Анализ пробелов     │  ← Где был голос? Какие частоты потеряны?
│     (спектральный)      │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  3. Поиск звуков        │  ← MFCC matching + категории
│     в библиотеке        │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  4. Вставка звуков      │  ← Crossfade, volume matching, spectral shaping
│     и восстановление    │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  5. Предпрослушивание   │  ← Пользователь корректирует результат
│     и коррекция         │
└─────────┬───────────────┘
          │
          ▼
    Финальный файл ✅
```

## 🛠 Установка

### Требования

- Python 3.9+
- FFmpeg (для обработки видео)

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/Wildpih/ClearSound.git
cd ClearSound

# Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/macOS
# или: venv\Scripts\activate  # Windows

# Установите зависимости
pip install -r requirements.txt

# Установите пакет
pip install -e .
```

### Установка FFmpeg

- **Windows:** `winget install ffmpeg` или скачайте с [ffmpeg.org](https://ffmpeg.org/)
- **macOS:** `brew install ffmpeg`
- **Linux:** `sudo apt install ffmpeg`

## 📖 Использование

### Основная команда — полный pipeline

```bash
# Обработать видеофайл
clearsound process video.mp4

# Обработать аудиофайл с указанием выхода
clearsound process audio.wav -o result.wav

# Без интерактивного режима
clearsound process video.mp4 --no-interactive

# С другой моделью Demucs
clearsound process audio.wav --model htdemucs_ft
```

### Только удалить голос (без восстановления)

```bash
clearsound remove-vocals audio.wav -o no_voice.wav
```

### Управление библиотекой звуков

```bash
# Показать содержимое библиотеки
clearsound library

# Сгенерировать базовые звуки
clearsound generate

# Добавить свой звук
clearsound add-sound rain.wav -c nature
```

### Интерактивные команды (во время предпрослушивания)

| Команда | Описание |
|---------|----------|
| `play` | Прослушать весь результат |
| `compare N` | Сравнить сегмент N (оригинал vs результат) |
| `play_segment N` | Прослушать сегмент N |
| `louder N` | Сделать вставку громче (+3 дБ) |
| `quieter N` | Сделать вставку тише (-3 дБ) |
| `volume N X` | Установить громкость на X дБ |
| `skip N` | Убрать вставку из сегмента |
| `restore N` | Вернуть вставку |
| `list` | Показать все сегменты |
| `accept` | Принять и сохранить |
| `quit` | Выйти без сохранения |

## 📁 Структура библиотеки звуков

```
sounds/
├── ambient/     # Фоновые шумы (шум комнаты, вентиляция и т.д.)
├── music/       # Музыкальные элементы (пэды, дроны)
├── nature/      # Природные звуки (дождь, ветер, птицы)
├── urban/       # Городские звуки (трафик, толпа)
└── foley/       # Звуковые эффекты (шаги, скрипы и т.д.)
```

Добавляйте свои .wav / .mp3 / .flac файлы в нужную категорию — они автоматически проиндексируются.

## ⚙️ Параметры конфигурации

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `--model` | `htdemucs` | Модель Demucs (`htdemucs`, `htdemucs_ft`, `mdx_extra`) |
| `--min-gap` | `0.3` | Минимальная длительность пробела (сек.) |
| `--crossfade` | `0.05` | Длительность кроссфейда (сек.) |
| `--no-interactive` | `false` | Пропустить интерактивный просмотр |
| `--no-generate` | `false` | Не генерировать звуки при пустой библиотеке |

## 🔧 Технологии

- **[scikit-learn](https://scikit-learn.org/)** — косинусное сходство для подбора звуков
- **[rich](https://rich.readthedocs.io/)** — красивый CLI интерфейс
- **[click](https://click.palletsprojects.com/)** — парсинг аргументов CLI
- **[FFmpeg](https://ffmpeg.org/)** — извлечение аудио из видео
