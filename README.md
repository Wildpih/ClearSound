# 🎵 ClearSound

**Интеллектуальное удаление голоса из аудио/видео и восстановление звуковой дорожки.**

ClearSound не просто удаляет голос нейросетью — программа анализирует спектральные «пробелы», оставшиеся после вырезания реплик (из-за чего звук становится глухим), автоматически подбирает наиболее подходящие чистые звуки из библиотеки, вставляет их с подгонкой громкости и спектра, и предоставляет **полноценный графический интерфейс (GUI) с видеоплеером**, где вы можете смотреть видео с новыми звуками и вносить правки в реальном времени!

---

## ✨ Возможности графического интерфейса (UI)

- 🗂️ **Хаб проектов (Multi-Project Hub)**:
  - Работа над несколькими роликами одновременно в одном окне
  - Карточки проектов: предпросмотр, статус (`Создан`, `В процессе`, `Готов`), длительность и количество найденных голосовых пауз
  - Быстрое переключение между открытыми проектами прямо из верхней панели инструментов
  - Персистентное сохранение на диск: все сегменты, подстановки и настройки сохраняются автоматически в `projects/<id>/project.json`
  - Поиск и фильтрация проектов по названию и статусу
  - Создание новых проектов, переименование и удаление в один клик
- 🎯 **Умное авто-сэмплирование (Track Donor Sounds)**:
  - Поиск чистых звуков-доноров прямо в самом видеоролике (в свободных от речи сценах)
  - Если в момент реплики пищал будильник, звонил телефон или раздался стук, программа находит идентичный чистый звук из этого же видео и вставляет его с точностью до миллисекунды и герца
- ⏰ **Акустическая классификация событий (Acoustic Event Typing)**:
  - Определение тональности, доминантной частоты (Hz) и транзиентности каждого фрагмента
  - Строгая дисквалификация непрерывного шума (дождь, ветер, гул) при обнаружении тональных сигналов или коротких импульсов
  - Расширенная библиотека звуков: цифровые будильники (2800 Гц), быстрые зуммеры, звонки телефонов, таймеры, стук в дверь, щелчки переключателей, тиканье часов, шаги
- 🎚️ **Параметрическое снятие глухоты (Spectral Un-muffling)**:
  - Точечное усиление (EQ Boost) частотной полосы приглушенного звука, убирающее эффект «бочки» и восстанавливающее яркость оригинального звучания
- 🎬 **Встроенный видеоплеер и аудиопроигрыватель**: смотрите видео в тандеме с восстановленным звуком.
- 🎧 **Поддержка наушников и выбор аудиоустройства**:
  - Прямой выбор устройства воспроизведения (Bluetooth-наушники, динамики, внешние ЦАП)
  - Тестовый сигнал (Test Chime) для мгновенной проверки звука
  - Расширенная шкала громкости до 150%
- 🎨 **Высококонтрастный студийный интерфейс**:
  - Темная студийная тема с четко различимыми подписями, индикаторами и кнопками
  - Адаптивные табличные строки без обрезания элементов
- 🔀 **Мгновенное переключение дорожек**:
  - `✨ Восстановленная (ClearSound)` — видео с новыми звуками окружения
  - `🔇 Без голоса` — чистое разделение нейросетью Demucs
  - `📼 Исходное` — оригинальное видео с голосом
- 📊 **Интерактивный таймлайн**:
  - Отображение аудиоволны (waveform)
  - Цветовая разметка всех обнаруженных голосовых сегментов
  - Клик по любому месту перемещает воспроизведение видео
- ✂️ **Редактор сегментов**:
  - Выбор звука для замены из рекомендаций нейросети или всей библиотеки
  - Тонкая регулировка громкости каждого фрагмента (`-24 dB` ... `+12 dB`)
  - Включение/отключение (skip) отдельных вставок
  - Мгновенное применение правок без повторного прогона нейросети
- 📚 **Менеджер библиотеки звуков**:
  - Категории: `ambient`, `music`, `nature`, `urban`, `foley`
  - Предпрослушивание звуков
  - Добавление своих аудиофайлов
  - Генерация базовых синтетических звуков в один клик
- 💾 **Экспорт**:
  - Экспорт аудиофайла (WAV / MP3)
  - Экспорт готового видеоролика с новой звуковой дорожкой (MP4 / MKV)

## 📋 Алгоритм работы

```
Входной файл (видео/аудио)
    │
    ▼
┌─────────────────────────┐
│  1. Удаление голоса     │  ← Demucs neural source separation
│     (стем вокала)       │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  2. Анализ пробелов     │  ← Где был голос? Какие частоты утеряны?
│     (MFCC + спектр)     │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  3. Поиск звуков        │  ← Cosine similarity + категории
│     в библиотеке        │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  4. Вставка звуков      │  ← Crossfade, loudness matching, spectral shaping
│     и сведение          │
└─────────┬───────────────┘
          │
          ▼
┌─────────────────────────┐
│  5. Просмотр и правки   │  ← Интерактивный плеер: смотрим видео,
│     в реальном времени  │    меняем звуки/громкость, проверяем результат
└─────────┬───────────────┘
          │
          ▼
    Готовое видео / аудио ✅
```

## 🚀 Быстрый старт (Windows)

1. Запустите **`install.bat`** (одноразовая установка зависимостей в виртуальное окружение).
2. Запустите **`run.bat`** для открытия графического интерфейса.
   *(Или просто перетащите видео/аудио файл на значок `run.bat`)*

## 🛠 Ручная установка

### Требования
- Python 3.9+
- FFmpeg (уже предустановлен в системе либо `winget install ffmpeg`)

### Установка в виртуальное окружение
```bash
git clone https://github.com/Wildpih/ClearSound.git
cd ClearSound

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
pip install -e .
```

### Запуск GUI через консоль
```bash
python -m clearsound.ui.app
# или с открытием файла:
python -m clearsound.ui.app "C:/path/to/video.mp4"
```

### Запуск консольного режима (CLI)
```bash
clearsound process "video.mp4"
```

## 📁 Структура проекта

```
ClearSound/
├── clearsound/
│   ├── config.py            # Конфигурация приложения
│   ├── main.py              # Точка входа (GUI и CLI команды)
│   ├── core/
│   │   ├── audio_utils.py   # DSP утилиты, FFmpeg ремукс видео, waveform peaks
│   │   ├── voice_remover.py # Шаг 1: Удаление вокала через Demucs
│   │   ├── gap_analyzer.py  # Шаг 2: Анализ спектральных пробелов и энергии
│   │   ├── sound_matcher.py # Шаг 3: MFCC подбор звуков из библиотеки
│   │   └── sound_inserter.py# Шаг 4: Вставка, тайм-стретч, кроссфейды
│   ├── library/
│   │   └── sound_library.py # Управление локальной библиотекой звуков
│   └── ui/
│       ├── app.py           # Запуск Qt-приложения
│       ├── theme.py         # Современная темная тема (QSS)
│       ├── main_window.py   # Главное окно со всеми вкладками
│       ├── video_player_widget.py   # Видеоплеер с переключением аудиодорожек
│       ├── timeline_widget.py       # Интерактивный таймлайн с сегментами
│       ├── segment_editor_widget.py # Таблица регулировки звуков и громкости
│       ├── library_widget.py        # Менеджер звуков
│       └── worker.py        # Фоновые потоки обработки (QThread)
├── sounds/                  # Библиотека звуков по категориям
├── output/                  # Папка для экспорта готовых файлов
├── install.bat              # Скрипт автоматической установки
├── run.bat                  # Быстрый запуск GUI
├── run_cli.bat              # Консольное меню (опционально)
├── requirements.txt
└── setup.py
```
